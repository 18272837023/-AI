# 统一测试入口

首选双击 `server/start-local.cmd`，访问 http://127.0.0.1:5310/ 。该地址直接展示原小程序界面，上传、任务进度、保存、自检和 DOCX 下载使用服务端真实接口。

也可单独执行 `node tools/preview/server.js`，访问 5199；其 `/v1/` 请求会转发到 5310，仍需启动服务端。

浏览器文件选择使用本地真实文件，预览器保存当前项目 ID，项目内容保存在服务端。模型模式显示在工作台。

完整步骤见 `docs/真实招标文件测试指南.md`。微信真机仍需配置可访问的 HTTPS 服务地址及合法域名，当前 localhost 入口用于本机浏览器测试。
