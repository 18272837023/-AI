# 真实招标文件测试指南

## 启动

双击 server/start-local.cmd，保持窗口运行，在浏览器打开 http://127.0.0.1:5310/ 。也可在 server 目录执行 node src/index.js。

依赖已在当前项目中安装。同一地址现在使用原来的小程序手机预览界面，直接连接服务端真实接口。旧的独立测试页面不再作为入口。

## 使用真实 AI

默认 mock 只验证流程。要评估 AI 效果，请把 server/.env.example 复制为 server/.env，填写：

```
LLM_MODE=live
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=你的密钥
LLM_MODEL=deepseek-chat
```

也可以使用你自己的兼容服务地址和模型。地址须为服务的基础地址，例如以 /v1 结尾，不含 /chat/completions。改完重启服务，页面应显示“真实模型”。live 缺密钥会拒绝启动，避免误以为正在使用 AI。

密钥仅填在本机 .env，不要发到聊天里。真实调用会产生所配服务的费用，并把文档内容交给该服务。

## 操作顺序

1. 在工作台点“新建技术标”，选择一份完整 PDF、DOCX 或 UTF-8 TXT，点击“开始解析”。扫描 PDF 暂不支持；多文件请先合并。
2. 解析报告展示真实抽取结果。通过“核对并修改解析数据”可修改结构化数据，保存前核对字段和 ID；保存会清除下游产物。
3. “确认解析结果”会生成施工图；核对后确认，进入大纲页。“开始生成正文”执行要素表和正文生成，进度来自实际任务。
4. AI 生成初稿后进入“待补字段”，固定显示项目经历、供应商与人员入场、培训与考核三项。可增删经历/培训条目，培训计划可请 AI 拟定建议，核对后再保存。页面不预填虚构演示数据。保存只补入相关段落或替换对应占位符，不重新生成整份正文；已精修段落如有冲突会保留并提醒。

完整编写底稿保留在“施工图与要素表 → 填写 / 编辑要素表”的独立入口。该高级页面编辑完整要素后仍会重新生成正文，有明确提示；它不是必经的待补字段环节。
5. 正文页上方切换章节，点击“编辑”，逐段修改并“确认修改”。内容保存到本机后自动重新自检。
6. “自检并导出”查看实际检查结果，进入导出页下载测试草稿。处理阻断后可下载正式 Word，无需模拟支付。
7. 刷新后从“项目列表”重新打开项目，继续使用已保存内容。

重新上传、重跑上游或保存上游修改，会清除下游产物；单独保存“待补字段”不会清除正文。切换项目、页面或刷新会放弃未保存的页面修改。下载只包含已保存内容。

## 当前边界

- 这是单机真实文件试用版，无登录和多用户隔离，请保持默认本机监听。
- Word 使用固定 A4、宋体 12 磅、1.5 倍行距及标题层级；尚未实现按各招标模板自动排版、目录、页码、PDF 导出。
- 当前覆盖检查验证要素关联及条款锚点，无法证明内容已实质响应；必须人工核对。strict 大纲提示会传给模型，但尚无强制逐章重排验收。
- 长文件抽取仍有上下文选择和截断，尤其须核对评分项有无遗漏。规则降级会显示提醒，生成稿不等于可直接投标。
- 扫描识别、图片、复杂表格格式还原及数据库多进程部署不在本次范围。

## 新接口

- PUT /v1/tenders/:id/parse
- PUT /v1/tenders/:id/blueprint
- PUT /v1/tenders/:id/elements
- PUT /v1/tenders/:id/sections

保存请求为 {"revision": 当前详情中的整数版本, "value": 完整阶段数据}。版本不符或任务运行中返回 409；结构错误返回 400。保存确认前会同步落盘。

GET /v1/tenders/:id/export 下载经自检门禁的正式 Word；加 ?draft=1 下载含测试草稿标记的 Word。无正文返回 400，有阻断的正式导出返回 409 并携带自检结果。

回归测试：在 server 目录执行 node --test test/*.test.js。


## 待补字段恢复说明

原结构来源于 miniprogram/utils/mock.js 的 F1—F4 和 docs/技术标生成框架.md 的素材装配阶段：类似项目经历、人员进场计划、培训与考核、现场与外部条件。按用户确认的流程固定保留三个核心分组；额外现场事实合并到入场资料组，方案写作任务由 AI 完成。对照说明见 docs/前后端业务流程对照.md。

已恢复：条目增删、固定选项、培训 AI 计划建议、声明未提供/不适用。声明仅产生风险提醒，不绕过原文强制要求和占位符检查。“稍后填写”按钮按之前要求保持移除。

补充信息通过 GET/PUT /v1/tenders/:id/supplements 读取和保存；POST /v1/tenders/:id/supplements/training-draft 生成待确认的培训建议。保存带 revision 防止覆盖其他窗口修改。已有项目仍使用原 ID，无需重新生成即可补充信息。
