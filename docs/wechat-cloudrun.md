## 行为与校验边界

小程序 `cloud-config.js` 配置环境与服务名，普通请求走 `wx.cloud.callContainer`。文件上传和导出以 48KB 分片经同一链路传递（Base64 后约 64KB，给请求元数据预留空间）。上传网络超时仅重试同一上传编号、同一片号，最多 3 次。不需要自有域名、临时通道或在手机上输入访问码。网页预览仍使用原 HTTP 方式。

更新此分片协议时，先发布 GitHub 最新提交到云托管，再用微信开发者工具上传小程序并设为体验版。只更新其中一端不会完成升级；新客户端遇到旧后端会明确提示先更新后端。

测试反馈修复版增加上传进度、保存 Word 到电脑与发送文件入口，以及“按技术分值扩写全稿”页面。云托管先部署后端，再上传小程序体验版。文件上限默认改为 200MB；如果服务环境变量已有 `MAX_FILE_MB=50`，需在“服务设置 → 基础信息 → 环境变量”改为 `MAX_FILE_MB=200`，本地 `.env` 同理。上传页读取后端实际限制显示。大文件仍使用 48KB 分片，不增加网关请求体积；单次上传会话有效期为 6 小时，失败时保留已上传的附件状态，重试不会重复添加成功附件。这里放宽的是文件体积，扫描图纸的识图/OCR 能力没有新增。

微信客户端的文件选择仍由 `wx.chooseMessageFile` 提供，从聊天文件中选择；电脑文件可先发送到“文件传输助手”，浏览器预览支持本机文件选择。不要调用不存在的小程序 `wx.chooseFile` 来假装支持电脑文件系统。

“按技术分值扩写全稿”可从正文编辑或导出页进入，填写目标总页数并查看各章分配。按每页约 420 字和技术分值占比估算，保留原文并追加论述，0 分人工章节不扩写，失败章节原样保留，成功章节保存并重算自检。重试会按当前实际篇幅补差额。页数不是排版保证，原有篇幅过多的章节不会被缩短，最终仍需 Word 排版核对；招标页数上限生效时不能设置超出上限的目标。真实事实不会因扩写而自动确认。

Word 导出补充标题编号、要素小标题、表名及显式表格网格。微信预览不兼容不代表下载失败，文件仍保留在小程序本地，可点“保存到电脑”或“发送文件”，再用 Word/WPS 打开。发送操作由用户在微信界面选择接收人。

大纲支持新增、改名、上移/下移和删除章节，操作关联同一评分项的要素与正文；新增章不伪造招标评分。删除的内容保留最近 20 次操作归档。正文及表格中的真实资料统一在“待补资料”确认，已绑定项目经历、入场和培训固定字段的标记不重复提问，保存后就地替换并重算自检。声明会立即保存，强制条款仍正常校验。

简化后的用户流程为：上传文件 → AI 解析 → 确认大纲 → 生成正文 → 自检并导出。独立的施工图确认页、要素表标签和编辑入口不再展示，后台仍自动准备编写数据，保留单章重试。生成完成直接打开正文；待补资料可从正文提醒或自检清单进入，保存不会重新生成已有正文。旧施工图/要素表路径分别跳转到大纲和待补资料，浏览器预览侧栏也隐藏旧入口。本轮流程简化仅需重新编译、上传小程序体验版，现有云托管接口可继续使用。

长目录 PDF 的项目要素按实际 PDF 页序取样，目录点引线不进入事实抽取上下文。原文校验支持相邻页续句，并将表格跳列引用还原成包含条款号的连续原文；只有可逐字定位的引用才通过。失败提示会显示具体字段或模型调用原因，不会以空白项目要素继续流程。该修复只需更新云托管后端。

生成页的失败章节提供“重试本章”，先补齐该章要素，再生成该章正文；其他成功稿和失败记录保留。任务运行中禁用重复提交，底部可继续生成全部未完成章节。此功能同时包含小程序页面及后端接口，先更新云托管，再更新开发者工具/体验版。

正文按章节性质深化：概况类目标每条要素约 250—450 字、常规组织安排约 400—700 字、重点施工或技术方案约 550—900 字，明确页数约束时压缩预算。每批最多展开三条要素，完整校验后合并成章；短段落、标题占位或重复粘贴不能冒充充分展开。已有正文不会自动改写，可在正文页按章“扩写”；最终仍需核对原文、技术适用性和实际导出页数。

每个微信用户只能访问自己新建的项目。新环境不会自动导入阿里云历史测试数据。

MySQL 保存项目和任务，COS 保存原件、分片和导出文件。异步任务启动前重新读取数据库；SQL 命名锁限制同时写入，轮询读取不被长任务阻塞，提交完成才回复成功。繁忙期间新的修改请求会提示稍后重试。进程重启会重新调度未完成任务；同一任务在数据库锁内检查完成状态以避免重复执行。重启时未完成的模型调用可能需要再次调用并消耗额度。

对象存储 `ai-tender/chunks/` 为临时上传分片，正常完成后删除；`ai-tender/exports/` 为导出缓存，可配置生命周期清理。原件在 `ai-tender/f_*`，不要对整个 `ai-tender/` 设置短期自动删除。

本地自动化测试不能代替微信环境联调。首次发布后须验证：真实手机建项目/上传 PDF 和 Excel、真实模型解析与生成、人工编辑保存、Word/PDF 下载、服务重新发布后项目和原件仍可读取，以及不同微信账号间项目不可互见。只有这些通过后才能确认云托管迁移完成。
